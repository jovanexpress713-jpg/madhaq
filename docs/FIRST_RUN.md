# تشغيل مذاق لأول مرة

## بيانات مدير النظام

- الدور: **مدير النظام**
- اسم المستخدم المقترح: `admin`
- كلمة المرور: **تحددها أنت عند أول تشغيل**، ولا توجد كلمة مرور افتراضية مشتركة.
- البريد الإلكتروني: **غير مطلوب** في الوضع المحلي.

## التسلسل

**شعار مذاق → الترحيب → إنشاء مدير النظام → تسجيل الدخول → النظام**

الحساب وبيانات الجلسة تحفظ محلياً على الجهاز في مفتاح مستقل عن قاعدة بيانات المعمل، لذلك إنشاء الحساب لا يحذف بيانات التشغيل الموجودة.
