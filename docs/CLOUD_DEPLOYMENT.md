# تشغيل MADHAQ بالسحابة

أصبح النظام الآن **offline-first**: يبقى `localStorage` هو التخزين المحلي، وعند تفعيل إعدادات Supabase يتحول الدخول والمزامنة إلى وضع متعدد الأجهزة مع تعارضات محسوبة بدلاً من الكتابة فوق بيانات جهاز آخر.

## 1) مشروع Supabase

تم تجهيز مشروع Supabase مجاني باسم **MADHAQ Dessert Factory**، وتطبيق مخطط السحابة عليه.

المخطط ينشئ:
- مساحة عمل MADHAQ.
- أعضاء وصلاحيات OWNER / ADMIN / ACCOUNTANT / OPERATOR / VIEWER.
- نسخة قاعدة بيانات مركزية مع رقم إصدار متزايد.
- سجل تدقيق.
- RLS على كل الجداول المكشوفة للعميل.

## 2) مفاتيح العميل

ضع في بيئة البناء:

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_PUBLISHABLE_KEY`
- `VITE_MADHAQ_WORKSPACE_ID` **اختياري**.

استخدم **publishable key فقط** في التطبيق. لا تضع `service_role` أو أي secret key في `.env` الذي يدخل إلى المتصفح أو APK.

إذا لم تضبط `VITE_MADHAQ_WORKSPACE_ID`، ينشئ MADHAQ تلقائياً أول مساحة عمل للحساب باسم **MADHAQ Dessert Factory** عند أول تسجيل دخول، ثم يحفظ معرفها محلياً ويستخدمها للمزامنة.

## 3) الحساب الأول

من شاشة MADHAQ السحابية:

1. أنشئ الحساب أو سجل الدخول.
2. إذا لم يكن للحساب مساحة عمل، ينشئ النظام مساحة **MADHAQ Dessert Factory** تلقائياً.
3. يصبح الحساب الأول OWNER.
4. يبدأ النظام بالمزامنة تلقائياً.

## 4) المزامنة

- عند الدخول: يتم فحص العضوية ثم قراءة النسخة المركزية.
- إذا كانت السحابة فارغة والجهاز يحتوي بيانات تشغيلية، تُرفع البيانات المحلية مرة واحدة.
- بعد ذلك تستخدم المزامنة رقم إصدار optimistic concurrency.
- تعديل جهاز آخر لا يُكتب فوقه تعديل محلي غير مرفوع؛ تظهر حالة `CONFLICT`.
- عند انقطاع الإنترنت يستمر النظام محلياً وتتحول الحالة إلى `OFFLINE`.
- عند عودة الاتصال يعاد الفحص تلقائياً.
- توجد مزامنة دورية كل 10 ثوانٍ بالإضافة إلى المزامنة بعد الحفظ المحلي.

## 5) الأمان

- كل الجداول السحابية عليها RLS.
- صلاحيات الكتابة مرتبطة بدور العضو في مساحة العمل.
- إنشاء مساحة العمل أصبح `SECURITY INVOKER` مع سياسات RLS مخصصة، وليس `SECURITY DEFINER` مكشوفة.
- لا توجد مفاتيح سرية داخل تطبيق MADHAQ.

## 6) حالة التحقق

تم اختبار وجود جداول السحابة الأربعة وتفعيل RLS عليها مباشرة في قاعدة البيانات، وتم تشغيل Supabase security advisors بعد التعديلات؛ لا توجد تنبيهات أمنية حالياً.

ملاحظات الأداء الحالية تقتصر على مؤشرات جديدة لم تُستخدم بعد لأن قاعدة البيانات ما زالت فارغة، وهذا متوقع عند بداية المشروع.
